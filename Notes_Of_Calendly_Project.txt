It specifically tells TypeScript to adapt to Node's dual-module world, where both ES Modules (import/export) and CommonJS (require) co-exist
This changes how TypeScript generates your JavaScript files. Instead of forcing everything into one format (like traditional CommonJS or ESNext), TypeScript dynamically looks at your project's context to decide what to output

ORM -> Object Relational Mapper  is for your RDBMS

The purpose is lets say i will feed in a programming language level code 
like JavaScript, Java , Python 
This ORM/ODM has a lot of logic writtend inside it, this ORM or ODM 
takes the machines level code to a SQL like Code 
SQL Code -> INSERT INTO User(id, name.....) Values(45, "Shalu",...)
